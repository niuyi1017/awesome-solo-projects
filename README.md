# awesome-solo-projects

> 一个聚焦单人/小团队趣味小项目的展示平台，不管你是敲代码的独立开发者，还是用 AI 工具玩转创意的普通人，只要你的作品足够好玩、足够脑洞，都能在这里获得曝光！

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

## 📖 关于本仓库

**awesome-solo-projects** 致力于收集和展示那些由单人或小团队创作的有趣、好玩、实用的小项目。我们欢迎独立开发者和 AI 创作者，只要你的作品有创意、有脑洞、能让人眼前一亮，就能在这里找到属于你的位置！

## ✨ 收录标准

### 类型要求
- ✅ **轻量化小项目**为主
- ✅ 趣味网页小游戏
- ✅ AI 生成的工具应用
- ✅ 冷门知识查询小程序
- ✅ 创意可视化图表
- ✅ 实用小工具
- ❌ 拒绝大厂商业产品
- ❌ 拒绝复杂重型应用

### 创作者要求
- 单人或 2-3 人小团队创作
- 独立开发者
- AI 工具创作者
- 业余创作者

### 核心门槛
- **好玩** 或 **实用**
- 有创意、有脑洞
- 能让人眼前一亮
- 独特的想法或实现

## 🎯 项目分类

## 📝 如何提交你的项目

### 提交格式
```markdown
- [项目名称](项目链接) - 项目简短描述（一句话介绍项目亮点）
  - 作者：[@你的用户名](你的主页链接)
  - 标签：`标签1` `标签2` `标签3`
```

### 提交步骤
1. Fork 本仓库
2. 在对应分类下添加你的项目
3. 确保遵循提交格式
4. 提交 Pull Request
5. 等待审核

### 提交示例
```markdown
- [表情包生成器](https://example.com) - 一键生成各种风格的表情包，支持 AI 自动配文
  - 作者：[@张三](https://github.com/zhangsan)
  - 标签：`AI` `图片处理` `趣味工具`
```
